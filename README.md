# Veris Metal Calculator

Небольшое офлайн-приложение Android для быстрого расчёта массы и стоимости круглой металлической заготовки.

Материалы:
- Сталь — 7850 кг/м³
- Алюминий — 2700 кг/м³
- Бронза — 8800 кг/м³
- БрАЖ — 7600 кг/м³

Ввод: диаметр (мм), толщина (мм), цена материала (₽/кг).
Вывод: объём, масса, стоимость.
